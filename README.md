# 天才斗篷的神秘代码 · A股盘后复盘工作台

单文件、零依赖的 A 股收盘复盘看板（纯静态 HTML，无构建步骤）。

## 模块

- **大盘总览**：6 大指数收盘点位、涨跌幅、成交额
- **市场情绪**：涨停 / 跌停、封板率、情绪环比（今日 vs 上一交易日）、连板结构、情绪小结
- **领涨方向**：同花顺「涨停板块榜」概念口径 + 东方财富行业维度双源对照，含来源标注与外链
- **涨停梯形图**：按连板高度分组，个股配色＝连板高度（首板浅 → 高板深）
- **首板动量池**：首板 + 量能 ≥2 倍 + 剔除 ST/科创板，含实时涨跌幅、是否晋级（查询时点封板状态判定）、开盘情况

## 口径说明

- 非实时收盘口径：15:00 后展示当日数据，次日 15:00 前展示前一日
- 缺失数据一律标注「未获取 / 待更新」，不做推断
- 涨跌配色遵循 A 股惯例：红涨绿跌

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署

托管于 GitHub Pages，入口为仓库根目录 `index.html`。
